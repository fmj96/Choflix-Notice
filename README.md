# Choflix Notice — 오디오 공지방송 스케줄러

[![Release](https://img.shields.io/github/v/release/fmj96/Choflix-Notice?label=%EC%B5%9C%EC%8B%A0%20%EB%B2%84%EC%A0%84)](https://github.com/fmj96/Choflix-Notice/releases/latest)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Build](https://github.com/fmj96/Choflix-Notice/actions/workflows/release.yml/badge.svg)](https://github.com/fmj96/Choflix-Notice/actions/workflows/release.yml)

윈도우 PC 를 방송 장비에 물려 두고, **정해진 시각에 안내 음성을 자동으로 내보내는** 프로그램입니다.
학교 종소리, 매장 안내방송, 사내 공지, 공장 교대 알림처럼 "매일 같은 시각에 같은 안내를 트는" 일을 대신합니다.

<sub>*A Windows scheduler that plays audio announcements at preset times — for school bells,
store and office PA systems. Korean UI.*</sub>

---

## 설치 — 이것만 하면 됩니다

[**최신 버전 내려받기**](https://github.com/fmj96/Choflix-Notice/releases/latest) 에서
`ChoflixNotice-Setup-x.y.z.exe` 를 받아 실행하세요.

- **관리자 권한이 필요 없습니다.** 잠긴 사무용 PC 에도 설치됩니다.
- **파이썬을 설치하지 않아도 됩니다.** 필요한 것이 모두 들어 있습니다.
- 설치 없이 쓰려면 `ChoflixNotice-x.y.z-portable.zip` 을 풀어 `ChoflixNotice.exe` 를 실행하세요.

> **SmartScreen 경고가 나오면** — 코드 서명 인증서가 없는 프로그램이라 윈도우가 경고를 띄웁니다.
> `추가 정보` → `실행` 을 누르면 됩니다. 걱정되면 아래 "소스에서 직접 빌드하기" 로 직접 만들어 쓰세요.
> 모든 릴리스는 이 저장소의 소스에서 [GitHub Actions](https://github.com/fmj96/Choflix-Notice/actions)
> 가 자동으로 빌드하므로, 빌드 과정을 누구나 확인할 수 있습니다.

예약 목록과 설정은 `%APPDATA%\ChoflixNotice\` 에 저장됩니다.
덮어 설치하거나 새 버전으로 올려도 **기존 예약은 그대로 유지됩니다.**

## 주요 기능

| 기능 | 설명 |
|---|---|
| **예약 방송** | 1회 / 매일 / 요일 반복 / N분 주기 — 네 가지 방식. 기간(시작일~종료일) 제한도 가능 |
| **음원** | 미리 만든 음성 파일 (wav · mp3 · ogg · flac) |
| **출력 장치 지정** | PA 앰프가 물린 USB 사운드카드 등 원하는 장치로만 내보냅니다. 시스템 기본 장치와 분리 가능 |
| **시작 차임** | 즉시 방송 앞에 "딩-동" 차임 재생. 기본 차임 내장, 원하는 파일로 교체 가능 (예약 방송에는 적용되지 않음) |
| **즉시 방송** | 예약과 무관하게 지금 바로 방송. 진행 중인 방송을 끊고 먼저 나가는 긴급 모드 지원 |
| **방송 중지** | 창 위쪽 붉은 버튼으로 재생 중·대기 중인 방송을 즉시 모두 중지. 트레이 메뉴에도 있음 |
| **현재 상태** | 창 위쪽 가운데에 지금 나가는 방송과 **진행 바**를 표시 (`▶ 방송 중: 점심시간 안내 (0:03 / 0:07)`) |
| **볼륨 / 페이드** | 전체 볼륨과 항목별 볼륨, 페이드 인·아웃, 연속 N회 재생과 재생 간격 |
| **트레이 상주** | 창을 닫아도 트레이에서 계속 동작. 윈도우 부팅 시 자동 실행 등록 |
| **재생 기록** | 언제 무엇이 나갔는지, 실패했다면 원인까지 기록. 방송이 끝나면 자동 갱신. CSV 내보내기 |
| **백업** | 예약 목록을 JSON 파일로 내보내고 다른 PC 에서 가져오기 |

## 소스에서 직접 빌드하기

설치 파일을 쓰지 않고 직접 빌드하려는 경우에만 필요합니다.
**파이썬이 먼저 있어야 하고**, 그 다음 패키지 설치가 이어집니다.

### 1. 파이썬 설치 (한 번만)

<https://www.python.org/downloads/windows/> 에서 **3.10 이상**을 받아 설치합니다.
설치 화면에서 아래 체크박스를 **반드시 켜세요**:

```
[v] Add python.exe to PATH
```

이걸 놓치면 `'python'은(는) 내부 또는 외부 명령...` 오류가 납니다.
체크를 잊었다면 설치 프로그램을 다시 실행해 `Modify` 로 고칠 수 있습니다.

> **함정 하나** — 윈도우 10/11 은 파이썬이 없어도 `python` 을 치면
> Microsoft Store 가 열립니다. 이건 실제 설치가 아니라 껍데기입니다.
> 반드시 python.org 설치본을 쓰세요.
> (`build_windows.bat` 은 이 껍데기를 걸러내고 안내 메시지를 띄웁니다.)

설치를 확인하려면 **새** 명령 프롬프트를 열고:

```
python --version
```

`Python 3.13.x` 처럼 나오면 성공입니다.

### 2. 패키지 설치 (자동)

`build_windows.bat` 또는 `run_windows.bat` 을 실행하면 가상환경과 패키지를
**알아서 설치합니다.** 직접 할 일은 없습니다.

- 내려받는 양: **약 300 MB** (PySide6 가 대부분)
- 걸리는 시간: 처음 한 번만 **5~10분**. 다음부터는 즉시 시작
- 필요한 디스크: 최소 1 GB 여유

사내망·프록시 환경이라 설치가 막히면, 명령 프롬프트에서 프록시를 먼저 지정하세요:

```
set HTTPS_PROXY=http://프록시주소:포트
```

### 3. 인터넷이 안 되는 PC 라면

방송용 PC 가 인터넷에 연결되지 않는 경우, **인터넷 되는 다른 PC**(윈도우·macOS·리눅스 아무거나)
에서 패키지를 미리 받아 USB 로 옮기면 됩니다.

**인터넷 되는 PC 에서:**

```
python tools/make_offline_bundle.py --python-version 314
```

`--python-version` 은 **방송용 PC 의 파이썬 버전**을 씁니다. `3.14.x` 면 `314`, `3.12.x` 면 `312`.
명령 프롬프트에서 `python --version` 으로 확인하세요. **버전이 다르면 설치되지 않습니다.**

프로젝트 폴더 안에 `wheels\` 가 생깁니다. 이 폴더를 포함해 **프로젝트 폴더 전체**를 USB 로 복사하세요.

**오프라인 PC 에서:**

```
build_windows.bat
```

`wheels\` 가 있으면 자동으로 인터넷을 쓰지 않고(`--no-index`) 그 폴더에서만 설치합니다.
화면에 `오프라인 모드: wheels 폴더에서 설치합니다` 라고 나오면 제대로 인식된 것입니다.

옵션:

| 옵션 | 설명 |
|---|---|
| `--python-version 313` | 대상 PC 파이썬 버전 (312 / 313 / 314 …) |
| `--platform win_arm64` | ARM 기반 윈도우용 (기본은 `win_amd64`) |
| `--runtime-only` | exe 빌드 없이 소스 실행만 할 때. 꾸러미가 작아집니다 |

> 만들어진 `wheels\manifest.json` 에 어떤 버전을 어떤 대상용으로 받았는지 기록됩니다.
> 나중에 "이 꾸러미가 어느 PC 용이었지?" 를 확인할 때 보세요.

## 빌드 방법

### 방법 A — 실행 파일로 만들어 쓰기 (권장)

파이썬 3.10 이상을 설치한 뒤, 프로젝트 폴더에서 `build_windows.bat` 을 더블클릭하거나:

```
build_windows.bat
```

가상환경 생성 → 패키지 설치 → 아이콘·차임 생성 → 빌드까지 한 번에 진행합니다.
끝나면 `dist\ChoflixNotice\` 폴더가 생깁니다. **이 폴더를 통째로** 원하는 곳에 옮기고
`ChoflixNotice.exe` 를 실행하세요. 파이썬이 없는 PC 에서도 동작합니다.

단일 exe 파일 하나로 만들려면:

```
build_windows.bat --onefile
```

다만 실행할 때마다 임시 폴더에 압축을 풀기 때문에 시작이 느리고,
백신이 오탐하는 경우가 있어 **부팅 자동 실행에는 폴더 배포를 권장**합니다.

> `.bat` 파일은 파이썬 스크립트를 부르기만 하는 얇은 껍데기입니다.
> 실제 빌드 로직은 `tools/build.py` 에 있어서, 원한다면 직접 실행해도 됩니다.
> ```
> python tools\build.py --onefile
> ```

### 방법 B — 소스에서 바로 실행

```
run_windows.bat
```

처음 실행할 때 가상환경과 패키지를 자동으로 준비합니다. 개발·테스트에 편합니다.
(내부적으로 `tools/launch.py` 를 실행합니다.)

수동으로 하려면:

```
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

### 설치가 잘 됐는지 확인

```
.venv\Scripts\python tools\selftest.py --play
```

패키지, 출력 장치, 코덱, 등록된 예약을 차례로 점검하고
`--play` 를 주면 실제로 차임을 한 번 재생합니다. 소리가 안 날 때 원인을 좁히는 데 쓰세요.

## 사용법

### 1. 출력 장치부터 고르기

**설정** 탭 → **출력 장치** 에서 방송용 장치를 선택하고 **소리 테스트** 로 확인합니다.
방송 앰프가 USB 사운드카드에 물려 있다면 그 장치를 고르세요. 이렇게 해 두면
PC 에서 나는 다른 소리(알림음, 유튜브 등)와 공지방송이 섞이지 않습니다.

고른 뒤 **설정 저장** 을 누르는 것을 잊지 마세요.

### 2. 예약 만들기

**예약 방송** 탭 → **추가**.

- **이름** — 목록에서 알아볼 이름 (예: `점심시간 안내`)
- **방송 내용** — 재생할 음성 파일
- **방송 시각** — 반복 방식을 고르고 시각을 지정

| 반복 방식 | 쓰임새 | 지정하는 값 |
|---|---|---|
| 1회 (지정 날짜) | 특정 행사 안내 | 날짜 + 시각 |
| 매일 | 매일 같은 시각 | 시각 |
| 요일 반복 | 평일 조회, 토요일 안내 | 시각 + 요일 |
| 주기 반복 | 영업시간 중 30분마다 | 시작~종료 시각 + N분 + 요일 |

시각은 **오전/오후 12시간제**로 입력하고 표시합니다. 입력칸은 크게 키워 두어
방송실 PC 를 조금 떨어져서 봐도 읽힙니다. 화살표는 끝에서 막히지 않고 한 바퀴
돕니다 (분 59 → 00, 시 12 → 1). 오전/오후 칸도 화살표로 바꿀 수 있습니다.

> 파일에는 24시간제로 저장됩니다. 표시만 12시간제라 예약을 내보내고 가져와도
> 시각이 어긋나지 않습니다.

- **기간 제한** — 체크하면 지정한 날짜 범위 안에서만 방송합니다 (예: 방학 기간 중단)
- **재생 옵션** — 볼륨, 연속 재생 횟수와 간격, 페이드

창 아래쪽에 **다음 방송 예정** 이 세 번치까지 미리 표시되므로,
저장 전에 의도한 시각이 맞는지 바로 확인할 수 있습니다. **미리듣기** 로 소리도 들어볼 수 있습니다.

### 3. 목록 다루기

- 맨 왼쪽 **사용** 체크를 끄면 그 예약만 잠시 쉽니다 (삭제하지 않아도 됩니다)
- 행을 **더블클릭** 하면 편집, **오른쪽 클릭** 으로 복제·삭제·지금 재생
- **길이** 칸에 음성 파일의 재생 시간이 표시됩니다. 연속 재생이면 `0:02 ×3` 처럼 보이고,
  마우스를 올리면 전체 길이가 나옵니다. 파일을 못 읽으면 `—` 로 표시됩니다
- **다음 방송** 칸에 남은 시간이 실시간으로 표시됩니다
- **열 경계선을 끌어 폭을 조절**할 수 있고, 그 폭은 저장되어 다음에도 유지됩니다.
  헤더를 끌면 열 순서도 바뀝니다. 헤더에서 오른쪽 클릭하면 `열 폭 기본값으로` /
  `내용에 맞춰 자동 조절` 을 쓸 수 있습니다
- 잠시 쉬게 하려면 해당 항목의 **사용** 체크를 끄면 됩니다 (삭제하지 않아도 됨)

### 4. 즉시 방송

**즉시 방송** 탭에서 파일을 고르고 **지금 방송**. 시작 차임은 여기서만 씁니다.
`진행 중인 방송을 끊고 먼저 내보내기` 를 켜 두면 다른 방송 중이어도 즉시 끼어듭니다.
주차 안내처럼 급한 공지에 쓰세요.

### 5. 트레이 상주와 자동 실행

**설정** 탭에서:

- `창을 닫아도 트레이에서 계속 실행` — X 를 눌러도 방송은 계속됩니다
- `프로그램 시작 시 트레이로 최소화` — 부팅 후 조용히 대기
- `윈도우 시작 시 자동 실행` — 현재 사용자 계정에 등록 (관리자 권한 불필요)

> 자동 실행은 **로그인해야** 동작합니다. 아무도 로그인하지 않는 무인 PC 라면
> 윈도우 `제어판 > 사용자 계정` 에서 자동 로그인을 켜 두세요.

### 6. 백업과 이관

**예약 방송** 탭의 **내보내기** 로 예약 전체를 JSON 파일로 저장할 수 있습니다.
다른 PC 에서 **가져오기** 로 그대로 복원됩니다.
음성 파일 자체는 포함되지 않으므로, 파일도 같은 경로에 함께 복사하세요.

## 알아두면 좋은 동작

**놓친 예약은 어떻게 되나요?**
PC 가 절전이었거나 프로그램이 꺼져 있어 예약 시각을 지나쳤다면,
설정의 **지연 허용**(기본 90초) 안쪽이면 늦게라도 방송하고, 그보다 더 늦었으면
건너뛰고 재생 기록에 `건너뜀` 으로 남깁니다. 두 시간 전 점심 안내가
갑자기 튀어나오는 일을 막기 위해서입니다.

**예약이 겹치면?**
같은 시각에 두 건이 걸려 있으면 하나씩 순서대로 나갑니다. 잘리지 않습니다.
긴급 방송만 진행 중인 방송을 끊고 먼저 나갑니다.

**출력 장치를 뽑으면?**
지정한 장치를 찾지 못하면 시스템 기본 장치로 방송을 계속하고 로그에 남깁니다.
장치가 없다고 프로그램이 멈추지는 않습니다.

**프로그램을 두 번 실행하면?**
이미 떠 있는 창이 앞으로 나오고 새 프로세스는 종료됩니다.
같은 공지가 두 번 나가는 사고를 막기 위한 장치입니다.

## 파일이 저장되는 곳

설정과 기록은 프로그램 폴더가 아니라 사용자 프로필에 저장됩니다.
`Program Files` 아래에 설치해도 권한 문제가 없습니다.

```
%APPDATA%\ChoflixNotice\
├─ settings.json      프로그램 설정
├─ schedules.json     예약 목록
├─ play_log.jsonl     재생 기록
├─ app.log            동작 로그 (문제 신고 시 첨부)
```

설정 탭의 **설정 폴더 열기** 버튼으로 바로 열 수 있습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 소리가 전혀 안 남 | `tools\selftest.py --play` 실행. 설정의 출력 장치와 전체 볼륨, 윈도우 볼륨 믹서 확인 |
| 다른 장치로 나감 | 설정 탭에서 장치를 고른 뒤 **설정 저장** 을 눌렀는지 확인 |
| MP3 가 안 열림 | `pip install --upgrade soundfile` (libsndfile 1.1 이상 필요). 급하면 WAV 로 변환 |
| 예약 시각에 안 나감 | 항목의 **사용** 체크와 **다음 방송** 칸을 확인하세요 |
| 자동 실행이 안 됨 | 해당 계정으로 로그인했는지 확인. 무인 PC 는 자동 로그인 필요 |
| 백신이 exe 를 차단 | PyInstaller 단일 exe 의 흔한 오탐입니다. 폴더 배포(기본)를 쓰거나 예외 등록 |
| `'python'은(는) ... 아닙니다` | 파이썬 미설치 또는 PATH 누락. 위 **준비물** 참조. 설치 후 **새** 명령 프롬프트를 여세요 |
| `python` 입력 시 Microsoft Store 가 열림 | 실제 설치가 아닙니다. python.org 설치본을 쓰세요 |
| 패키지 설치가 중간에 멈춤 | 방화벽·프록시·디스크 공간 확인. 프록시는 `set HTTPS_PROXY=...` |
| 인터넷이 안 되는 PC | `tools/make_offline_bundle.py` 로 wheels 폴더를 만들어 함께 복사. 위 **준비물 3** 참조 |
| 오프라인 설치 시 `No matching distribution` | wheels 가 대상 PC 파이썬 버전과 다릅니다. `python --version` 확인 후 `--python-version` 을 맞춰 다시 받으세요 |
| `.bat` 실행 시 `'lse'은(는) ... 아닙니다` | 배치 파일 줄바꿈이 LF 로 바뀐 경우입니다. cmd.exe 는 CRLF 가 필요합니다. `.gitattributes` 가 이를 강제하니, 편집기에서 줄바꿈을 CRLF 로 저장하세요 |
| `.bat` 안 한글이 깨짐 | 현재 `.bat` 은 ASCII 만 씁니다. 한글 안내는 `tools/*.py` 가 출력하므로 배치 파일에 한글을 넣지 마세요 |

문제가 계속되면 `%APPDATA%\ChoflixNotice\app.log` 를 확인하세요.

## 개발자용

### 구조

```
choflix/
├─ app.py           진입점, 로깅, 단일 실행 감시
├─ models.py        ScheduleItem / Settings, 다음 실행 시각 계산
├─ store.py         설정·예약 저장 (원자적 쓰기)
├─ audio.py         장치 조회, 디코딩, 재생 엔진 (워커 스레드 + 우선순위 큐)
├─ scheduler.py     1초 주기 예약 감시, 재생 작업 조립
├─ logbook.py       재생 기록 (JSONL)
├─ paths.py         저장 경로
├─ autostart.py     윈도우 Run 키 등록
└─ ui/              PySide6 화면 (탭 4개 + 편집 대화상자 + 트레이)

tools/
├─ build.py         빌드 로직 (가상환경·패키지·리소스·PyInstaller)
├─ launch.py        소스 실행 (가상환경 자동 준비 후 앱 기동)
├─ make_chime.py    기본 차임 생성
├─ make_icon.py     앱 아이콘 생성
├─ make_offline_bundle.py  오프라인 설치용 wheel 꾸러미 생성
└─ selftest.py      설치 진단
```

설계상 알아둘 점:

- **재생은 워커 스레드 하나**가 우선순위 큐를 소비합니다. UI 는 절대 오디오를 직접 만지지 않습니다.
- **작업 하나에 스트림 하나**를 엽니다. 세그먼트마다 열면 장치를 여닫는 데만 수백 ms 가 들어
  차임과 공지 사이가 벌어집니다. 샘플레이트가 다른 음원은 스트림 하나에 맞춰 리샘플합니다.
- **시각 계산은 로컬 시간(naive)** 기준입니다. 공지방송은 벽시계대로 동작해야 합니다.

### 배치 파일에 로직을 두지 않는 이유

`cmd.exe` 는 배치 파일에 **CRLF 줄바꿈**을 요구하고, 파일 본문을 **콘솔 코드페이지**
(한국어 윈도우는 CP949)로 해석합니다. macOS·리눅스에서 만든 UTF-8 + LF 파일을 그대로 두면
`) else (` 같은 구문이 잘려 `'lse'은(는) 내부 또는 외부 명령...` 오류가 나고 한글도 깨집니다.

그래서 `.bat` 은 **ASCII 만 쓰고 CRLF 로 저장**하며, 파이썬 스크립트를 부르는 일만 합니다.
줄바꿈에 예민한 `else` 나 괄호 블록도 쓰지 않습니다. 실제 로직과 한글 안내는
`tools/build.py`, `tools/launch.py` 에 있습니다. `.gitattributes` 가 줄바꿈을 고정합니다.

### 리소스 다시 만들기

```
python tools/make_chime.py     assets/chime.wav (기본 차임)
python tools/make_icon.py      assets/icon.ico, icon.png (앱 아이콘)
```

아이콘 모양은 `choflix/ui/widgets.py` 의 `app_pixmap()` 이 코드로 그립니다.

### 실행 옵션

```
python run.py              창을 띄우고 시작
python run.py --tray       트레이로 최소화한 채 시작 (자동 실행용)
python run.py --verbose    자세한 로그
```

### 요구 사항

파이썬 3.10 이상, `requirements.txt` 참조.
윈도우 10/11 기준으로 만들었지만, 코드 자체는 macOS·리눅스에서도 실행됩니다
(자동 실행 등록만 윈도우 전용).
